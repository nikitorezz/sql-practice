# Timed sets and take-homes

Phase 4 (Dec 7 – Dec 20): two timed sets a week (3 mixed problems in 45 minutes) and one 2-hour take-home simulation a week.

## A timed set

One folder per session: `timed-sets/2026-12-08-set-1/`

- `README.md`: the three problems (links), start time, the 45-minute limit, and the result, for example `2 / 3 correct, 41 min`. Add one line on what cost you time.
- One `.sql` file per problem, with the same header as a solution (copy it from `templates/solution.sql`, set `Topic: mixed`).

Don't look anything up during the set. Problems you got wrong also go into `solutions/` afterwards, redone properly, and into the mistake log.

## A take-home

One folder per take-home: `timed-sets/2026-12-12-takehome-ecommerce/`

- `README.md`: the brief in your own words, time spent, your answers and the 3–5 findings you would send.
- `queries.sql` (or one file per question), with comments explaining each step.
- Small CSV extracts only if needed; never commit large data (the `.gitignore` already skips `data/`).
