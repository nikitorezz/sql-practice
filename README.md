## How it's organised

| Folder | What's in it |
|---|---|
| [`solutions/`](solutions) | One `.sql` file per problem, grouped by source: LeetCode, DataLemur, pgexercises, StrataScratch, HackerRank, other |
| [`patterns/`](patterns) | Eight analytics patterns written from memory, each with a note on when to use it |
| [`timed-sets/`](timed-sets) | Timed problem sets and take-home simulations |
| [`templates/`](templates) | The header every solution file starts with |
| [`scripts/`](scripts) | `new.py` creates a solution file, `progress.py` rebuilds the section above, `save.py` does that and pushes |

Each solution file starts with a short header: problem, source, link, topic, the pattern in one line, dialect, date, time taken, and whether I needed the solution.
